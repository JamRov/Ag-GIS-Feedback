# Ag-GIS Feedback

Public bug reports, ideas and help for Ag-GIS. Product source and installer releases are maintained separately in a private repository.

- [Report a problem, suggest an improvement or ask for help](https://github.com/JamRov/Ag-GIS-Feedback/issues/new/choose)
- [Browse existing reports](https://github.com/JamRov/Ag-GIS-Feedback/issues)
- [Reporting and progress guide](docs/FEEDBACK.md)

Reports and attachments are public. Never include original farm/customer data, passwords, access tokens or private screenshots. The Ag-GIS Feedback button lets you review a report before sharing, or save/email it without a GitHub account.

Maintainers track new → needs information/planned → in progress → ready to test, and close after verification. Release downloads require private access or delivery by your administrator.
